# Шаблон `docs/usage/*.md`

Один документ описывает одну пользовательскую задачу и один поддерживаемый
golden path.

```markdown
# Получение Example через ExampleFacade

## Когда использовать

## Зависимость

Только подтверждённый `implementation(libs.exampleFacade)`.

## Минимальный пример

Компилируемый фрагмент на реальном public API.

## Обязательная конфигурация

Только подтверждённые ключи, без secrets.

## Ожидаемый результат

## Ограничения и типичные ошибки

## Evidence

- `path/to/ExistingConsumerTest.kt` — подтверждает вызов API.
- `path/to/PublicFacade.java` — подтверждает public entrypoint.
```

Не создавай пример, если нет подтверждения в source, тестах или существующем
consumer. Не копируй большой production-класс целиком. Не выдавай внутреннюю
реализацию за public API. Все evidence paths должны существовать.

Все семь H2-заголовков из шаблона обязательны. Если dependency или
configuration не нужны, явно напиши это в соответствующем разделе. В Evidence
должен быть хотя бы один существующий repository-relative path в обратных
кавычках.
